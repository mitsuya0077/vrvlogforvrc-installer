# VR Vlog for VRC

VRChatの写真撮影に合わせて、設定した1〜5秒の動画を残す Windows アプリです。Windows 10 22H2以降・Windows 11（x64）に対応しています。

## ダウンロード

**[Windows用インストーラーをダウンロード（v0.1.29）](https://github.com/mitsuya0077/vrvlogforvrc-installer/releases/download/v0.1.29/VRVlogForVRC-0.1.29-Setup.exe)**

ダウンロードした `VRVlogForVRC-0.1.29-Setup.exe` を実行してください。既存環境には上書きして更新できます。

[最新版の変更内容](https://github.com/mitsuya0077/vrvlogforvrc-installer/releases/latest)

現在のインストーラーは未署名です。Windows が確認画面を表示する場合は、配布元とファイル名を確認してから実行してください。

## 更新とデータの保存

アプリ起動時に更新を確認し、更新するか後で行うかを選べます。更新・再起動時の進捗も表示します。保存済みの動画・コメント・設定は更新後も残ります。

v0.1.17〜v0.1.18からの更新が起動時に進まない場合は、上のインストーラーを手動で実行してください。v0.1.16以前からの更新もインストーラーを手動で実行してください。

設定・編集データの保存先：`%LOCALAPPDATA%\VRVlogForVRC`

動画とJPEG写真の標準保存先は `%LOCALAPPDATA%\VRVlogForVRC\clips` です。「接続と設定」から変更できます。変更前に保存した素材は元の場所に残り、引き続きライブラリから利用できます。
