# VR Vlog for VRC

VRChatの写真撮影に合わせて、2秒の動画を残す Windows アプリです。Windows 11（x64）に対応しています。

インストーラーは [Releases](https://github.com/mitsuya0077/vrvlogforvrc-installer/releases) からダウンロードできます。`VRVlogForVRC-*-Setup.exe` を実行してください。

現在のインストーラーは未署名です。Windows が確認画面を表示する場合は、配布元とファイル名を確認してから実行してください。

バージョン 0.1.3 以降は、アプリが起動中に更新を確認し、撮影や書き出しが終わった後、または次回起動時に更新します。保存済みの動画と編集情報は更新後も残ります。

素材と設定の保存先：`%LOCALAPPDATA%\VRVlogForVRC`
